# Phase 9 — Git-like Version Control (Compare / Branch / Publish)

**Agent:** Antigravity (backend versioning + diff engine) + Codex (version history UI)  
**Depends on:** Phase 0 (schema has schedule_run + parent_run_id)  
**Blocks:** Nothing  
**Estimated effort:** Large (3–5 days)

---

## Goal

Expand the existing draft/published/archived system into a full
**Git-like timetable lifecycle**:
- Branch from any version to create a new draft
- Compare two versions to see what changed (diff)
- Publish a draft to make it the active schedule
- Rollback to any past published version
- View version history with metadata

Do NOT build merge branches — that's too complex. Instead:
> Branch = create alternate draft from a base version  
> Diff = compare two versions  
> Publish = choose the winner

## Version Model (from Phase 0 — already in schema)

```python
class ScheduleRun(Base):
    id: UUID
    workspace_id: UUID
    version_label: str          # "v1", "v2", "Draft: Relaxed Constraints"
    status: str                 # "draft" | "published" | "archived"
    solver_score: float | None  # quality score
    explanation: JSONB | None   # infeasibility / soft violation report
    parent_run_id: UUID | None  # which version this was branched from
    branch_name: str | None     # human readable branch label
    is_manual: bool             # was this created by manual edits?
    created_at: datetime
    published_at: datetime | None
    archived_at: datetime | None
```

  └── v5 (Published — June 12, branched from v3 Draft B)

## Backend Endpoints

```
GET  /api/v1/workspaces/{id}/schedule-runs/
     → list all versions (sorted by created_at desc)

POST /api/v1/workspaces/{id}/schedule-runs/{id}/branch
     body: { branch_name }
     → create new draft from this version

GET  /api/v1/workspaces/{id}/schedule-runs/compare?a={id}&b={id}
     → diff report: changed assignments, affected resources, score delta

POST /api/v1/workspaces/{id}/schedule-runs/{id}/publish
     → mark this run as published, archive currently published

POST /api/v1/workspaces/{id}/schedule-runs/{id}/archive

POST /api/v1/workspaces/{id}/schedule-runs/{id}/rollback
     → same as branch but labels it as a rollback draft
```

## Diff Engine (Backend)

```python
class ScheduleDiffEngine:
    def diff(self, run_a_id: UUID, run_b_id: UUID) -> DiffReport:
        assignments_a = self.get_assignments(run_a_id)
        assignments_b = self.get_assignments(run_b_id)
        
        # Compare by (task_id, group_id) key
        moved = []
        for key in assignments_a:
            if key in assignments_b:
                a, b = assignments_a[key], assignments_b[key]
                if a.timeslot_id != b.timeslot_id or a.location_ids != b.location_ids:
                    moved.append(ChangedAssignment(before=a, after=b))
        
        affected_resources = self.compute_affected_resources(moved)
        
        return DiffReport(
            moved_count=len(moved),
            changes=moved,
            affected_resources=affected_resources,
            score_delta=run_b.solver_score - run_a.solver_score,
            soft_violation_delta=...,
        )
```
