## Historical material

Research and academic project notes that still have reference value live under [`archive/research`](archive/research/README.md). Archived documents describe ideas at a point in time; they are not implementation instructions or claims about the current product.

The repository intentionally removes completed phase plans, chat logs, duplicate generated HTML exports, and UML v1 so stale material cannot be mistaken for the active design.
